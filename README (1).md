# 江苏大学智能图书馆

这是星光杯本地参赛原型，包含馆藏发现、空间与选座、事务反馈和馆员工作台。首页的 AI 馆员在无 Key 时使用明确标注的本地知识库与规则引擎，支持常见问答、书目位置续查、中文时段选座和记录编号查询；配置 DeepSeek 后切换真实模型。预约与反馈始终由读者确认后写入系统。

两种版本均可向 AI 提问“介绍一下江苏大学”“介绍一下江苏大学图书馆”。简介采用有来源与日期的官网摘编，维护入口见[学校与图书馆简介](开发文档/数据维护.md#学校与图书馆简介)。

## 接手项目

需要直接演示时，可以用浏览器打开 [手机电脑离线版 HTML](江苏大学智能图书馆_手机电脑离线版.html)。若源码压缩包中尚无此文件，先运行 `python -B -X utf8 scripts/build_offline.py` 生成。离线 AI 支持本次会话 10 轮问答，超限后点击“开始新对话”。当前开发程度、已测流程及后续工作见[开发程度评估与验收](开发文档/开发程度评估与验收.md)。

1. 在 Windows 双击 [启动智能图书馆.cmd](启动智能图书馆.cmd)，或在项目根目录运行 `python -B -X utf8 agent_backend/server.py`。按 [运行与接入说明](运行与接入说明.md) 检查 Python 和配置。
2. 打开 [读者首页](http://127.0.0.1:8765/) 检查读者流程。侧边栏的馆员工作台使用弹窗中展示的本机演示账户。
3. 从 [开发与发布](开发文档/开发与发布.md) 选择对应的回归测试。完整演示和验证记录放在 [网页预览](网页预览/)。

本地服务默认运行在 `127.0.0.1:8765`，使用 SQLite 和规则演示助手。真实模型需要单独配置 DeepSeek Key。书单与座位来自项目资料，预约、停用和反馈属于本站演示记录。校方业务系统及统一身份认证仍待对接。分享 `江苏大学智能图书馆_演示原型.zip` 时，按 [发布说明](开发文档/开发与发布.md#发布演示包) 核对内容范围。
